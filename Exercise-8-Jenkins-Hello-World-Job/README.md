# Exercise 8 - Jenkins Hello World Job

## Objective
Create a Jenkins Freestyle job that executes a shell script.

## Files
- hello-world.sh: Prints Hello, Jenkins!

## How to run
Run ./hello-world.sh in the terminal.

## Expected output
Hello, Jenkins!

## Jenkins configuration
- Job name: HelloWorld
- Job type: Freestyle project
- Build step: Execute shell
- Build command: ./hello-world.sh

## Expected result
The Jenkins Console Output should display Hello, Jenkins!
and the build result should be SUCCESS.
